Source Configuration

NDJSON (enabled): Each line is a separate JSON object

{{"{"}}\"name\": \"Alice\", \"age\": 30{{"}"}}
{{"{"}}\"name\": \"Bob\", \"age\": 25{{"}"}}

JSON array (disabled): A single JSON array containing all objects

[
  {{"{"}}\"name\": \"Alice\", \"age\": 30{{"}"}},
  {{"{"}}\"name\": \"Bob\", \"age\": 25{{"}"}}
]

Per-line XML (enabled): Each line is a separate, complete XML element

<record><name>Alice</name><age>30</age></record>
<record><name>Bob</name><age>25</age></record>

Full XML document (disabled): A single XML document with a root element containing child elements

<records>
  <record>
    <name>Alice</name>
    <age>30</age>
  </record>
  <record>
    <name>Bob</name>
    <age>25</age>
  </record>
</records>
