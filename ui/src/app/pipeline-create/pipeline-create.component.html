Why enable sampling?

The AI rule sends the entire file to the AI model for validation. For files with more than 1,000 rows, this can be slow and expensive. Sampling randomly selects a subset of rows (default 200) which is typically sufficient to detect systematic data quality issues like format errors, range violations, and cross-column inconsistencies — while keeping AI costs low and processing fast.

Validation Rules

Row mode: The endpoint is called once per row. Each call receives a single row as a key-value object. Best for real-time validation against external services.

Batch mode: The endpoint is called once with all rows in a single request. More efficient for bulk validation, but the endpoint must handle the full dataset.
