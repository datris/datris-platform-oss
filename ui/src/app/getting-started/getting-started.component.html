Datris Platform UI

The First AI Agent-Native Data Platform

This is your testing and configuration environment for Datris. Use it to set up Taps that pull data from external sources, define Pipelines that validate and transform records, push data through Ingestion, and Search the results — all from one place. When you're happy with how things behave here, the same configuration runs in production via the API, CLI, or MCP.

What each tab does

MCP

Connect an Agent — Claude, Cursor, or any MCP-compatible client — to Datris. This tab gives you a ready-to-paste config block and shows the tools agents will have access to (create pipelines, ingest data, run searches, etc.). Start here if you want an AI agent driving Datris for you.

Agent Monitor

Live monitor of connected agents. Every MCP tool call is shown as it happens — agent name, arguments, record count, response size, status, and latency. Click any row to expand the full request and response. Use this tab to watch what your agents are actually doing and debug their behavior in real time.

Assistant

In-product AI agent for end-to-end tap and pipeline building. Describe the data you want; the Assistant finds an external source, builds the tap, creates the pipeline, runs it, and shows you the result — all in one chat. Watch the model's reasoning and every tool call inline. The fastest way to onboard a new data source.

Data Catalog

Organize your data assets into catalogs — logical groups of related taps and pipelines. Catalogs are created when building taps and pipelines (manually or via the Assistant). View, manage, and delete entire catalogs from here.

Taps

Taps are data feeds — scheduled or on-demand jobs that pull data from an external source (REST API, file, etc.) and hand it off to a pipeline. Use this tab to create a tap, preview its output, run it manually, and link it to a pipeline.

Pipelines

Pipelines define how data is validated, transformed, and stored. The 9-step wizard walks you through schema, AI data quality rules, AI-generated transformations, and the destination. Every record you ingest flows through a pipeline.

Ingestion

Watch data flow in. This tab shows recent ingestion runs, row counts, validation failures, and lets you drill into individual jobs. It's your live feedback loop while you're tuning a pipeline.

Search

Query the data you've ingested. Run SQL, browse tables, or ask a natural- language question and let Datris generate the answer. This is where you confirm that the records made it through end-to-end.

Secrets

Store API keys, database passwords, and other credentials that taps and pipelines reference by name. Values are stored in Vault — never in plain config.

Configuration

Platform-wide settings: AI provider/model, default behaviors, and environment info. Most users only visit this tab once during setup.

Docs ↗

Full reference documentation, tutorials, and API specs. Opens in a new tab.

Suggested first run

  1. Open the Assistant and describe the data you want (e.g., "Pull current weather data from a public API and create a pipeline").
  2. Watch the agent find a source, create the tap, build the pipeline, and run it — providing credentials inline if needed.
  3. Click straight into the created tap or pipeline from the chat to inspect or tweak it.
  4. See records arrive in Ingestion.
  5. Query the results in Search.

Alternative: Open Taps to create a single tap manually, or connect an external MCP agent (Claude, Cursor, etc.) to drive the entire workflow programmatically.
