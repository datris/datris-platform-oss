AI Configuration is locked on the trial.

During the free trial, Datris runs on shared Anthropic and OpenAI keys with cost-conscious models (Claude Haiku 4.5 for chat, Claude Opus 4.6 for code generation, OpenAI text-embedding-3-small for vector search) so you can try every feature without bringing your own credentials. A dedicated Datris instance unlocks the full platform: bring your own Anthropic or OpenAI keys for unlimited usage, pick any model (Claude Opus 4.6, Sonnet 4.6, GPT-5.4, text-embedding-3-large), get your own isolated Postgres database with persistent storage, eliminate shared rate limits, and run on your own custom domain with a production SLA.
