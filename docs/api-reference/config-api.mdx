title: "Configuration API"

The Configuration API lets you upload validation schemas and generate JSON Schema or XSD from sample data using AI.

## Upload Config File

Upload a validation schema to the platform's configuration store (MinIO).

```
POST /api/v1/config/upload
Content-Type: multipart/form-data
```

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `file` | form-data | Yes | The configuration file to upload |
| `type` | form-data | Yes | File type: `validation-schema` or `javascript` |

The uploaded file is stored at `{env}-config/{type}/{filename}` in MinIO and can be referenced in pipeline configurations.

### Example

```bash
curl -X POST http://localhost:8080/api/v1/config/upload \
  -F "file=@my-schema.json" \
  -F "type=validation-schema"
```

### Response

```json
{
  "filename": "my-schema.json",
  "path": "s3://oss-config/validation-schema/my-schema.json"
}
```

### Errors

A `type` other than `validation-schema` or `javascript`, or a file name with no usable segment or with characters outside letters, digits, `.`, `_` and `-`, returns HTTP 400 with `{"error": "<message>"}`. A storage failure returns HTTP 500 with the same body shape.

## Generate Schema from Sample Data

Use AI to generate a JSON Schema or XSD from sample data. The generated schema is stored in MinIO and can be referenced in pipeline configurations for data quality validation.

```
POST /api/v1/config/generate-schema
Content-Type: application/json
```

Generating a schema stores the file pipelines validate against, so it is a pipeline change: an API key needs `pipeline:update` (any scope), and a signed-in user needs to be an admin or an editor (one [limited to catalogs](/user-auth#catalog-access) needs edit or own on at least one). Schema names are shared by every pipeline in the installation: a name that a pipeline you may not update already uses, whether or not its file is stored yet, is refused (see Errors below). Generating again under a name used only by pipelines you may update replaces that schema, as before.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `type` | string | Yes | Schema type: `json-schema` or `xsd` |
| `name` | string | Yes | Name for the generated schema file |
| `sampleData` | string | Yes | Sample data content for the AI to analyze |

### Example

```bash
curl -X POST http://localhost:8080/api/v1/config/generate-schema \
  -H "x-api-key: $DATRIS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "json-schema",
    "name": "orders",
    "sampleData": "[{\"id\": 1, \"email\": \"jane@example.com\", \"total\": 249.99}]"
  }'
```

### Response

```json
{
  "filename": "orders.json",
  "path": "s3://oss-config/validation-schema/orders.json",
  "schema": "{ ... generated JSON Schema ... }"
}
```

For `xsd` type, the filename uses `.xsd` extension and the response contains a generated W3C XML Schema.

When `DATRIS_AI_SAMPLE_VALUES=false`, the schema is generated from a value-free skeleton of the sample and the response also carries `"valuesWithheld": true`. See [AI Configuration](/ai-configuration) for the switch.

### Errors

Missing or invalid input returns HTTP 400 with `{"error": "<message>"}` naming the problem: a body that is not valid JSON or not a JSON object, missing fields (`type`, `name`, `sampleData`), a field that is not a string, an unknown schema type, a blank name or sample, or a name that is not a usable file name. Input errors are reported before the model is called. A model or storage failure, or a failure reading the stored pipelines, returns HTTP 500 with the same body shape and stores nothing.

A caller without `pipeline:update` gets HTTP 403 with `errorKind: capability_denied`. A name used by a pipeline the caller may not update gets HTTP 409 with `{"error": "A validation schema named '<name>.json' is already in use. Choose another schema name."}` (`.xsd` for an XSD), before the model is called and with nothing stored; the answer names no pipeline and is the same for every caller. Choose another name.
