# JavaScript Row Transformations (Deprecated)

JavaScript row functions (`transformation.rowFunctions` with `function: "javascript"`) are deprecated in v1.4.0. Use [AI Transformation (CodeGen)](ai-transformation.md) instead — describe your transformation in plain English and Datris generates a Python script that runs locally.

JavaScript row functions still work in the pipeline server for backward compatibility with existing pipeline configurations, but are no longer exposed in the UI or CLI.
