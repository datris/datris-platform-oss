# Release Notes

## v1.2.2 — March 25, 2026

### New MCP Tool

**`update_secret`** — Agents can now self-configure their AI provider API keys without human intervention. Scoped to AI-related secrets only (anthropic, openai, ollama, embedding) — agents cannot access database credentials or other infrastructure secrets.

- Added as Step 0 in the recommended agent workflow: "Configure AI"
- Agents can write keys but cannot read them back (sensitive fields are masked)

### MCP Registry & PyPI Publishing

- Published to the [MCP Registry](https://registry.modelcontextprotocol.io) as `io.github.datris/datris`
- Published to [PyPI](https://pypi.org/project/datris-mcp-server/) as `datris-mcp-server`
- Install: `pip install datris-mcp-server`
- Run: `PIPELINE_URL=http://localhost:8080 datris-mcp-server`
- `server.json` added to repo root for MCP Registry metadata
- `pyproject.toml` added for PyPI packaging with hatchling build
- `server.py` refactored with `main()` entry point for pip install usage
- README updated with PyPI install instructions and MCP Registry verification tag

### Health Check Improvements

- **Qdrant** — Switched from gRPC client to HTTP GET (`/collections` on port 6333). Eliminates gRPC channel leak errors when Qdrant is not running.
- **Milvus** — Switched from MilvusClientV2 to HTTP POST (`/v2/vectordb/collections/list`). Eliminates gRPC channel leak and `ManagedChannel` garbage collection warnings.

### Docker Config Sync

- Added missing vector store secret names to `docker/config/application.yaml`: embeddingSecretName, qdrantSecretName, weaviateSecretName, milvusSecretName, chromaSecretName, pgvectorSecretName. Fixes pgvector and vector store health checks showing "not configured" in Docker deployments.

### UI Changes

- MCP tab is now the first tab and default landing page
- Logo click navigates to home page
- MCP "What AI Agents See" workflow updated with Step 0: Configure AI
- `update_secret` tool added to MCP tool catalog and playground
