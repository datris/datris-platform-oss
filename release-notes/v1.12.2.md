# Release Notes

## v1.12.2 — July 27, 2026

**Claude Opus 5 support, and a fix for a month-after-install credential expiry.**

- **Claude Opus 5.** Anthropic's newest model (released July 24) is now fully supported and is the recommended Anthropic model for both chat and code generation — same price as Opus 4.8 with better results. Fresh installs default to it; existing installs keep their configured model and can switch in Configuration → AI Providers.
- **Fix: internal credential expired a month after install.** An internal service credential was silently issued with a 32-day lifetime, after which restarting the platform could fail until the secret store was restarted. Credentials are now long-lived, are refreshed on every startup, and expired ones are cleaned up automatically. The fix applies automatically on upgrade — no action required.

**Upgrading**

- Standard upgrade: `docker compose pull && docker compose up -d`. No configuration changes required.
- CLI / MCP server: version bump only, no functional changes.
