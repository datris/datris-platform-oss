# Release Notes

## v1.15.0 — August 10, 2026

**Azure OpenAI support — run Datris AI on your Azure resource.**

Datris now supports Azure OpenAI as a first-class AI provider alongside Anthropic, OpenAI, and Ollama. If your organization standardizes on Azure — for procurement, private networking, or data-residency reasons — every AI feature (the chat assistants, code generation, schema inference, NL→SQL, and semantic-search embeddings) can now run against model deployments on your own Azure OpenAI resource.

- **All three AI slots.** Choose Azure OpenAI independently for the AI Provider, CodeGen, and Embedding sections in Configuration → AI Providers, and mix it freely with the other providers — for example Azure for chat with Anthropic for CodeGen.
- **One key, entered once.** The shared API Keys panel gains an Azure OpenAI field; like the other providers, the key is stored durably, so switching a section between providers never loses it.
- **Deployment-name aware.** Azure addresses models by the deployment names you create, so the model field takes your deployment name. Tip: name deployments after the model they serve (the Azure portal's default) so model-specific handling applies automatically.
- **Install-time setup.** The one-command installer now offers Azure OpenAI when you don't have a direct Anthropic or OpenAI key, and first-boot seeding can configure everything from your Azure details.
- **Built for how Azure behaves.** Responses stream under the hood so long-running reasoning calls complete reliably, and both the current and legacy Azure endpoint styles work.

Embeddings on Azure are opt-in: fresh Azure-only installs default to the bundled local embedding service, and you can switch to an Azure embedding deployment whenever you've created one. See the [AI Configuration guide](https://docs.datris.ai/ai-configuration) for setup.

Also in this release:

- **Fix: signing back in after a session expires no longer requires a full page refresh** — the app now returns you to the login screen directly, from any of the chat surfaces.
- **Fix: updating a single provider's API key through the API no longer clears the other providers' stored keys.**
- **Fix: data uploaded through the AI assistants can no longer be silently garbled** when the model sends plain text where encoded content was expected — the platform now detects this and ingests the text as-is.

**Upgrading**

- Standard upgrade: `docker compose pull && docker compose up -d`. No configuration changes required.
- To adopt Azure OpenAI on an existing install, open **Configuration → AI Providers**, pick Azure OpenAI in any section, and enter your key, resource endpoint, and deployment name.
