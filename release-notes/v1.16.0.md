# Release Notes

## v1.16.0 — August 11, 2026

**Amazon Bedrock support — run Claude through your AWS account.**

Datris now supports Amazon Bedrock as a first-class AI provider alongside Anthropic, OpenAI, Azure OpenAI, and Ollama. If your organization runs on AWS, the chat assistants and code generation can now use Claude models served from your own AWS account — IAM authentication, AWS billing, and no Anthropic API key required.

- **IAM-native auth, keys optional.** Enter AWS credentials once in Configuration → AI Providers, or leave them blank when Datris runs on AWS infrastructure and it uses the server's IAM role — zero stored secrets.
- **Live model discovery.** The model dropdown shows what your AWS account and region can actually invoke — discovered from AWS rather than hardcoded, including cross-region inference profiles, with a custom-entry option for anything else.
- **Claude Fable 5 and the full Claude lineup.** Chat recommends Claude Fable 5; CodeGen recommends Claude Opus 5. Fable 5 requires a one-time data-retention opt-in on your AWS account — the platform explains exactly what to do when it applies, and the docs cover it.
- **Deliberate opt-in.** Bedrock is only ever chosen explicitly — AWS credentials you already use for S3 destinations never silently become your AI provider. The one-command installer offers Bedrock when you don't have a direct provider key.
- **Reasoning included.** Extended thinking works the same as with the direct Anthropic provider.

Embeddings and web search aren't served by Bedrock: embeddings default to the bundled local service (or pair with OpenAI / Azure OpenAI), and web search stays on Anthropic or OpenAI. See the [AI Configuration guide](https://docs.datris.ai/ai-configuration) for setup.

Also in this release:

- **Clearer provider credentials panel.** The panel in Configuration → AI Providers is now grouped per provider with a short explainer of how shared credentials work; Azure OpenAI and Amazon Bedrock each have their own section.
- **Credentials hide immediately after saving** instead of remaining visible on screen until a page refresh.
- **Fix: a model saved under one provider no longer appears in another provider's model list** after switching a section between providers.
- **Refreshed model recommendations.** Claude Fable 5 is now the recommended chat model for the Anthropic provider.

**Upgrading**

- Standard upgrade: `docker compose pull && docker compose up -d`. No configuration changes required.
- To adopt Bedrock on an existing install, open **Configuration → AI Providers**, pick Amazon Bedrock in the AI Provider and/or CodeGen section, enter your AWS credentials and region on the right (or leave the keys blank to use an IAM role), pick a model, and save.
