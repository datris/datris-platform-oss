# Release Notes

## v1.14.0 — August 4, 2026

**Incremental taps — scheduled taps now fetch only what's new.**

Recurring taps can now remember where they left off. After each successful run the platform stores a small bookmark for the tap; the next run picks it up and pulls only the records that were added or changed since. A tap that syncs a growing source runs at a constant size forever, instead of re-fetching everything until it hits the output limit.

- **No gaps, no duplicates.** The bookmark only advances after a run succeeds — a failed run leaves it in place, so the automatic retry re-fetches the same window and nothing is ever skipped. Destinations with key fields absorb any overlap by updating in place.
- **See it and reset it.** Each tap on the Taps page now has a sync-state view showing its current bookmark, when it was committed, and a one-click reset for a full re-fetch. Agents get the same via two new MCP tools.
- **AI-built taps are incremental by default.** When you describe a recurring source to the Assistant or the tap wizard, the generated script now uses change-detection automatically whenever the source supports it — modified-since filters, ID watermarks, continuation cursors, or content hashing, in that order of preference.
- **Manual backfills stay safe.** Running a tap with an explicit date range doesn't move the bookmark — the schedule continues from where it was.

**MongoDB destinations now support upsert.**

Pipelines writing to MongoDB can declare key fields, so a record that changes at the source updates its existing document in place instead of accumulating duplicates. This was previously blocked by over-strict validation even though the loader supported it.

**MCP improvements.**

- Two new tools for reading and rewinding a tap's sync state (63 tools total).
- Every tool in the MCP tab's playground now executes — 28 tools that previously returned an error when run from the playground work correctly.
- The AI assistant follows firmer honesty rules: a repeated request like "run it again" always triggers a real run and reports that run's actual result.

See the [Taps guide](https://docs.datris.ai/taps#incremental-sync-state) for the incremental sync contract and examples.

**Upgrading**

- Standard upgrade: `docker compose pull && docker compose up -d`. No configuration changes required.
- Existing taps are unaffected until their scripts opt into the bookmark contract — ask the Assistant to make a scheduled tap incremental, or regenerate its script.
