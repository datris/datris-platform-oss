# Release Notes

## v1.13.1 — July 28, 2026

**Store your tap scripts in GitHub — every save is a commit.**

Tap Python scripts can now live in a GitHub repository you connect, instead of Datris's built-in storage. Enable it under **Configuration → Code Repository**.

- **A commit on every save.** Whether a script is saved from the tap wizard, built by the Assistant, or pushed through the API, it lands in your repository as a normal commit — reviewable, diffable, and revertable with the git tooling your team already uses.
- **Runs are pinned to the exact version they were saved at.** Scheduled runs execute the precise commit you approved, served from a local cache — they keep working even if GitHub is unreachable, and every run records which version it executed.
- **Edit tap code in your own IDE.** Commit changes to the repository directly; when the tap is next opened in Datris, it spots the newer version and offers to load it. If someone changes a script in the repository while you're editing the same tap in Datris, your save is stopped with a clear message instead of silently overwriting their work.
- **Move taps one at a time, in either direction.** Existing taps stay on built-in storage until you move them — each row in the Taps list shows where its script lives and can be moved with one click. Moving back is just as easy.
- **Safe, scoped access.** Datris needs only a fine-grained personal access token limited to the one repository, with read/write access to its contents. A built-in connection test verifies everything before you enable it. GitHub Enterprise Server is supported.

See the [GitHub Script Storage guide](https://docs.datris.ai/tap-github-storage) for setup, including a step-by-step token walkthrough.

**Upgrading**

- Standard upgrade: `docker compose pull && docker compose up -d`. No configuration changes required — the feature is opt-in and nothing changes until you connect a repository.
- CLI / MCP server: taps created by AI agents respect your repository setting automatically.
